# Deterministic validation contract

Re-fetch the posting by provider and ID immediately before evaluation. A published detail response matching that ID and containing a substantial JD is the V1 live signal. 404/410 means closed. HTTP 200 alone, redirects to generic careers pages and search snippets are insufficient. Timeouts, rate limits, malformed data and missing descriptions are errors, not closed vacancies. Never mark an error processed. Live status is time-stamped and only valid at the check time.
