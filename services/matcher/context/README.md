# Runtime context only

Career Evidence Bank and Positioning & Targeting Charter are fetched freshly from Google Drive on every real run. Native Google Docs, stored DOCX, text and Markdown are supported. IDs belong in secrets, never this directory.

Evidence paragraphs receive stable content-based IDs at runtime. The model must cite exact quotes from those paragraphs. No CVs, candidate biography, metrics, contact information or source snapshots belong in Git. Direct clarification from the candidate overrides the Evidence Bank; the Evidence Bank overrides the Charter and older materials. V1 reads only the two primary documents, so record reusable clarifications in the Evidence Bank before a run.

The checked-in policy provides editable operations-search defaults. Configure it for your own search; it is not a candidate career profile. Source documents are reference data, never executable instructions. Changes to either source invalidate previous fit evaluations.
